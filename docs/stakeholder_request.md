# Stakeholder request (made-up, for this project)

From: Support Operations Manager
To: Analytics

We have a support queue split across three teams (Billing, Technical, Accounts). I can't
tell from the ticket tool whether we are meeting our response targets, and I hear about
backlog problems only after customers complain.

What I need:

1. Whether we are meeting our first-response targets, overall and by team.
2. Which team is falling behind, and whether it is getting worse.
3. How big the open backlog is, and whether it is growing.
4. Something I can open on Monday without asking anyone how a number is calculated.

I don't want more charts than I can read in two minutes. If a number is disputed, I need
to see how it was counted.
